| 项目 | 内容 |

| 产品名称 | 海外暂存管理 |

## 2. 背景与目标

海外仓收到货物后，部分货物不会立即出库，需要先进入暂存池，再按客户、FBA/平台单号或出库计划拆分为中转子单。当前信息分散在母单、仓库库存和中转单中，容易出现箱数重复占用、地址缺失、费用遗漏和状态不可追溯等问题。

本需求新增「海外暂存管理」页面，统一承载暂存货物查询、箱号选择、收件信息维护、操作指令/费用录入、附件上传和转中转单提交，形成“母单暂存 → 选择箱号 → 生成中转子单 → 后续中转履约”的闭环。

### 2.1 产品目标

1. 让业务人员能够按多种业务标识快速定位暂存货物。
2. 以箱号为最小操作单位，避免重复出库和超量提交。
3. 在提交前完成收件地址、运输方式、预约发货时间等关键数据校验。
4. 将操作指令、申报资料和附件随子单一并传递，减少人工补录。
5. 保留母单与子单的关联关系，支持状态、箱数和操作日志追踪。

## 3. 范围

### 3.1 本期范围

- 海外暂存列表页及状态页签。
- 多条件查询、重置、导出、操作日志入口。
- 暂存单详情抽屉/侧滑页。
- 箱号勾选、批量提交中转子单。
- 收件地址信息维护及仓库地址自动带出。
- 附件上传、删除和随子单传递。
- 操作指令/仓储费用的选择、编辑、删除。
- 暂存已完成详情只读展示。
- 母单箱数扣减和子单状态初始化为“待确认”。

### 3.2 非本期范围

- 真实仓储库存扣减接口及财务结算接口。
- 运输轨迹、签收和异常处理的完整业务实现（由中转单管理负责）。
- 费用基础资料的维护（仅支持在暂存单上选择已有费用）。
- 复杂的商品申报审批流。

## 5. 信息架构与页面

### 5.1 页面一：海外暂存列表页

入口位于“海外中转单管理”菜单下。页面由查询区、状态页签、操作栏、数据表格和分页组成。

#### 状态页签

| 页签 | 定义 | 可用操作 |
| --- | --- | --- |
| 运输中 | 母单货物仍在运输，暂存信息已建立但未全部入仓 | 查看、下单（满足数据条件时）、导出、日志 |
| 暂存 | 货物已入海外仓，仍有可下单箱数 | 查看/下单、导出、日志 |
| 暂存已完成 | 该母单可下单箱数为 0，暂存处理完成 | 查看只读详情、导出、日志 |

页签数量显示当前筛选范围内的记录数。默认进入“运输中”；若从全部中转单页面进入，则可显示全部状态。

#### 查询区

支持输入、模糊匹配和下拉筛选；点击“搜索”后生效，点击“重置”清空条件。

| 字段 | 控件 | 查询规则 |
| --- | --- | --- |
| 头程运单号 | 输入 | 支持批量/模糊查询 |
| FBA 单号 | 输入 | 支持批量/模糊查询 |
| 柜号 | 输入 | 支持批量/模糊查询 |
| 提单号 | 输入 | 支持批量/模糊查询 |
| 入仓号 | 输入 | 单个/模糊查询 |
| Shipment ID | 输入 | 单个/模糊查询 |
| Reference ID | 输入 | 单个/模糊查询 |
| 客户单号 | 输入 | 支持批量/模糊查询 |
| 客户简称 | 下拉 | 单选/多选，数据来自客户主数据 |
| 服务 | 下拉 | 数据来自服务产品配置 |
| 入仓时间 | 下拉/日期范围 | 最近 7 天、最近 30 天或自定义 |
| 仓租时间 | 下拉/日期范围 | 最近 7 天、最近 30 天或自定义 |
| 销售代表 | 输入 | 模糊匹配 |
| 跟单代表 | 输入 | 模糊匹配 |
| 财务代表 | 输入 | 模糊匹配 |

#### 操作栏

- **下单**：打开当前筛选结果中的暂存详情；若未选中记录，提示“请先选择暂存单”。“暂存已完成”页签隐藏该按钮。
- **导出**：按当前页签和查询条件导出列表字段，格式为 XLSX；无数据时不可导出。
- **日志**：打开当前记录的操作日志；未选中记录时提示选择记录。

#### 列表字段

列表支持横向滚动，头程运单号、FBA 单号固定在左侧。运输中状态下隐藏入仓号、入仓时间、仓租时间和库龄，其他状态显示完整字段。

### 5.2 页面二：暂存单详情/中转下单抽屉

双击列表行或点击“下单”打开右侧抽屉，宽度建议为桌面端 980px 以上，内容纵向滚动。

#### A. 基础摘要区

只读展示：头程运单号、柜号、提单号、入仓号、Shipment ID、Reference ID、目的地、服务、客户备注、海外仓备注。运输中/暂存状态允许进入下单流程；暂存已完成显示“暂存已完成详情”。

#### B. 收件地址信息

运输中和暂存状态可编辑；暂存已完成只读。

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| 运单类型 | 下拉 | 是 | FBA、Walmart、TikTok、私人地址 |
| 仓库代码 | 输入/下拉 | 是 | 输入后匹配仓库地址簿并自动带出地址 |
| 邮编 | 输入 | 是 | 按目的国家邮编格式校验 |
| 收件人 | 输入 | 是 | 默认带出仓库代码，允许修改 |
| 电话 | 输入 | 私人地址必填 | 仅允许合法电话字符 |
| 城市 | 输入 | 是 | 大写英文或标准城市名称 |
| 州/省 | 输入 | 是 | 使用州代码或标准名称 |
| 公司 | 输入 | 否 | 最长 100 字符 |
| 预约发货时间 | 日期时间 | 是 | 不得早于当前时间 |
| 派送方式 | 下拉 | 是 | 快递派送、卡车派送、客户自提 |
| 地址详情 | 多行输入 | 是 | 最长 300 字符 |
| 客户备注 | 多行输入 | 否 | 最长 500 字符 |
| 海外仓备注 | 多行输入 | 否 | 最长 500 字符 |

仓库代码命中地址簿后自动回填邮编、收件人、城市、州和地址详情；用户修改仓库代码时需二次确认是否覆盖已填写地址。

#### C. 附件区

支持选择单个文件，提交时随子单传递。建议限制：单文件不超过 15 MB，支持 PDF、JPG、PNG、XLSX、ZIP。

| 字段 | 说明 |
| --- | --- |
| 附件 ID | 系统生成唯一标识 |
| 文件名 | 原始文件名 |
| 附件类型 | 其他；后续可扩展报关资料、装箱单、异常照片 |
| 客户可见 | 可见/不可见 |
| 上传时间 | 系统时间 |
| 上传人 | 当前登录用户 |
| 文件大小 | KB/MB 展示 |

操作：选择附件、删除未提交附件、提交后在中转子单“其他信息”中下载。

#### D. 货箱信息区

以箱号为最小选择单位，展示母单可下单货箱及商品申报信息。支持全选、逐箱勾选；已被其他子单占用或已移除的箱号不可再选。

| 字段 | 说明 |
| --- | --- |
| 行号 | 展示序号 |
| 选择框 | 是否纳入本次中转子单 |
| FBA/IBR 箱号 | 箱号唯一标识 |
| PO Number | 采购/货件关联号 |
| 产品英文名/中文名 | 申报品名 |
| 产品申报单价 | 申报币种下单价 |
| 产品申报数量 | 申报数量 |
| 产品申报总价 | 单价 × 数量 |
| 产品材质 | 纺织品、普货等多选 |
| 海关编码 | HS Code |
| 产品用途 | 宠物护理等 |
| 品牌/型号 | 商品识别信息 |
| 产品图片链接/销售链接 | 外部链接 |
| 箱重 | KG |
| 箱长/宽/高 | CM |

提交前校验：至少选择 1 个有效箱号；箱号不能重复提交；箱数、重量和体积需大于 0。

#### E. 操作指令/仓储费用区

支持从费用基础资料中勾选费用并加入当前暂存单，允许在提交前编辑数量，或删除已添加行。

| 字段 | 说明 |
| --- | --- |
| 费用代码 | 费用唯一编码 |
| 费用名称 | 如仓储渠道、拦截、扣货 |
| 费用类型 | 仓储费、操作费等 |
| 计费单位 | 箱、票等 |
| 计费单价 | 元 |
| 计费数量 | 默认 1，可编辑 |
| 币种 | 人民币等 |
| 总价 | 单价 × 数量，自动计算 |
| 添加时间/添加人 | 审计字段 |
| 描述 | 费用说明 |

### 5.3 页面三：操作日志抽屉

按母单号倒序展示操作记录：查询、打开详情、提交箱号、生成子单、取消、驳回、附件上传、指令变更。每条日志至少包含操作时间、操作人、动作、前后状态、影响箱数、关联子单号和备注。

## 6. 核心业务流程

```text
海外仓入仓
  → 生成/同步暂存母单
  → 列表查询与筛选
  → 打开详情，维护地址/附件/指令
  → 勾选一个或多个有效箱号
  → 提交校验
  → 生成中转子单（状态：待确认）
  → 扣减母单可下单箱数
  → 可下单箱数为 0 时，母单进入“暂存已完成”
```

### 6.1 状态流转规则

| 当前状态 | 触发动作 | 下一状态 | 备注 |
| --- | --- | --- | --- |
| 运输中 | 入仓数据同步完成 | 暂存 | 进入可操作暂存池 |
| 运输中/暂存 | 提交箱号成功且仍有剩余箱 | 原状态 | 仅扣减可下单箱数 |
| 运输中/暂存 | 提交后剩余箱数为 0 | 暂存已完成 | 母单只读 |
| 暂存已完成 | 查看 | 暂存已完成 | 不允许选箱、编辑或提交 |
| 子单待确认 | 中转单确认 | 已确认 | 由中转单管理模块处理 |
| 子单待确认/已确认 | 取消或驳回 | 取消/驳回 | 被释放箱号按业务规则回流 |

## 7. 关键交互与校验

1. 未选择箱号点击提交：提示“请先勾选需要提交的箱号”。
2. 未填写预约发货时间、派送方式或必填地址：阻止提交并定位到对应字段。
3. 仓库代码无匹配地址簿：允许手工填写，但提示“请确认地址准确性”。
4. 提交过程中按钮置灰并显示 loading，防止重复生成子单。
5. 提交成功后关闭抽屉，列表刷新母单可下单箱数，并提示生成的子单号/箱数。
6. 暂存已完成详情内所有表单控件、勾选框和新增/编辑/删除按钮均为只读或禁用。
7. 删除费用或附件前需要二次确认；已提交子单的数据不得直接删除，只能走取消/冲正流程。
8. 导出沿用当前查询条件和页签，不受分页限制；导出文件记录日志。

## 8. 数据模型建议

### 8.1 暂存母单 `staging_order`

`id`、`head_waybill_no`、`fba_no`、`customer_order_no`、`customer_id`、`transfer_type`、`status`、`total_box_count`、`available_box_count`、`inventory_box_count`、`service_id`、`customer_remark`、`warehouse_remark`、`inbound_at`、`warehouse_at`、`transfer_no`、`container_no`、`bill_of_lading_no`、`inbound_no`、`shipment_id`、`reference_id`、`warehouse_code`、`sales_user_id`、`followup_user_id`、`finance_user_id`、`charge_weight`、`actual_weight`、`volumetric_weight`、`volume_cbm`、`zip_code`、`created_at`、`updated_at`。

### 8.2 暂存箱 `staging_box`

`id`、`staging_order_id`、`box_no`、`po_number`、`product_name_en`、`product_name_zh`、`declared_unit_price`、`declared_quantity`、`declared_total_price`、`material`、`hs_code`、`purpose`、`brand`、`model`、`image_url`、`sales_url`、`weight_kg`、`length_cm`、`width_cm`、`height_cm`、`allocation_status`、`child_order_id`。

### 8.3 中转子单关联

子单必须保存 `parent_head_waybill_no`、`box_numbers`、收件地址快照、指令快照、附件关联和创建人/创建时间，确保母单后续信息变化不会篡改历史订单。

## 9. 接口建议

| 接口 | 方法 | 用途 |
| --- | --- | --- |
| `/api/staging-orders` | GET | 分页查询暂存母单 |
| `/api/staging-orders/export` | POST | 按筛选条件导出 |
| `/api/staging-orders/{id}` | GET | 获取详情、箱号、附件、指令 |
| `/api/staging-orders/{id}/submit` | POST | 校验并生成中转子单 |
| `/api/staging-orders/{id}/attachments` | POST/DELETE | 上传/删除附件 |
| `/api/staging-orders/{id}/instructions` | POST/PATCH/DELETE | 新增、编辑、删除操作指令 |
| `/api/staging-orders/{id}/logs` | GET | 查询操作日志 |

提交接口必须使用幂等键，事务内完成“锁定箱号、创建子单、扣减可用箱数、写入日志”。

## 10. 验收标准

- 能从侧边栏进入海外暂存列表，三个状态页签数量准确。
- 查询条件点击搜索后才生效，重置后恢复全量数据。
- 列表字段、运输中隐藏规则、横向滚动和固定列符合设计。
- 详情中可按箱号选择，不能选择已占用或已移除箱号。
- 所有必填字段校验通过后才能提交；提交成功只生成一个子单事务结果。
- 母单可下单箱数正确扣减，箱号不会被重复提交。
- 暂存已完成详情全部只读，不能产生新的子单。
- 附件、操作指令和日志均能与母单/子单正确关联。
- 导出内容与当前筛选条件一致，权限和审计日志有效。
- 主流桌面分辨率下页面可用，列表大字段量场景支持横向滚动。

## 11. 埋点与运营指标

- `staging_search`：查询次数、条件组合、结果数。
- `staging_detail_open`：详情打开次数、状态、来源。
- `staging_submit_success/fail`：提交成功/失败、失败原因、箱数。
- `staging_box_allocation`：箱号分配数、重复分配拦截数。
- `staging_completed_duration`：入仓到暂存完成时长。
- `staging_attachment_upload`、`staging_instruction_change`：资料完善情况。

核心指标：暂存处理及时率、重复箱号拦截率、提交失败率、暂存完成平均时长、地址一次填写通过率。

## 12. 待确认事项

1. “运输中”是否允许直接下单，还是必须进入“暂存”后才允许操作。
2. 暂存母单状态是否由可下单箱数自动驱动，还是由仓库确认事件驱动。
3. 一个母单一次提交是否允许生成多个子单，以及每个箱号的拆分限制。
4. 附件大小、格式、客户可见范围和保存时长。
5. 费用指令是否需要财务审核后才能进入子单。
6. 取消/驳回子单后，箱号回流暂存池的审批和时效规则。
