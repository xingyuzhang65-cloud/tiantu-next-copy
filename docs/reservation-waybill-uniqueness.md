# 预留运单唯一性校验：交互与提示文案

## 业务规则

同一实际运单仅可通过「预留运单号」关联一个预留单。使用系统运单号、客户单号或 FBA 号输入时，先识别运单，再按内部运单 ID 校验；同一预留单的多个编号对应同一运单时合并关联。编辑时排除当前预留单，校验其他全部预留单。普通匹配来源不参与此次预留关联的占用校验。

待确认：取消后是否释放占用。当前原型按所有预留单状态参与校验处理，包括已取消；以实际运单身份判重，不以客户、日期、渠道、仓库或当前列表筛选条件缩小检查范围。

## 交互

1. 粘贴、回车、失焦时解析并校验，切换客户后重新识别；保留全部输入，重复项展示红色标签「重复预留」。同一表单重复输入同一编号自动合并并轻提示。
2. 字段下展示重复票数、系统运单号、占用预留单号及状态；批量输入逐票列出冲突，保留其他编号及全部已填字段，不自动保存部分数据。
3. 支持逐个点击标签的 × 移除；提供「移除全部重复运单」。一号多票时只移除已占用运单，保留已选择的可用运单；已占用候选不可新增勾选，但可以取消已有勾选。
4. 保存按钮保留可操作状态，点击后再次校验最新本地数据；失败时保持弹层及表单，定位预留运单号字段，不写入部分数据。修正后再次保存。
5. 编辑排除自身；历史上已存在跨单重复时展示所有占用预留单，不静默迁移或清理已有数据。

### FBA 号对应多票运单

输入 FBA 号匹配多票运单时不自动关联全部候选。点击或悬浮编号标签，浮层展示匹配总票数、可关联票数、已占用票数及已选票数，每票分别显示系统运单号、客户单号、FBA 号与可关联/已占用状态。

已占用运单展示占用预留单号和状态，复选框禁选；已有选择在操作期间变为占用时，可取消勾选。只对最终选中的实际运单校验和保存；同一 FBA 下未选的占用运单不阻止保存。未选择时提示选择，标签显示“待选运单”；选择后标签显示“已选 N 票”。全部候选被占用时提示当前编号无法关联。

移除冲突时，仍有可用候选的 FBA 编号保留，供用户重新选择；全部候选均被占用时移除该编号。

测试客户：`深圳天图电子有限公司 (VIP)`。测试 FBA 号：`FBA261116TEST01`。

| 系统运单号 | 初始状态 |
| --- | --- |
| HD2611169501 | 已关联 MOCKYL202611169501，禁选 |
| HD2611169502 | 可关联 |
| HD2611169503 | 可关联 |

测试时在新增预留单中选择上述客户，输入 FBA 号后按回车，点击标签选择可用运单，再填齐其他必填信息保存。同一 FBA 的两票可用运单可分别保存至不同预留单。示例保存后会保留占用状态，刷新不会重置用户的测试结果。

## 研发实现提示词

请在现有「预留单」的新增、编辑表单中，为「预留运单号」增加唯一性校验。同一实际运单只能关联一个预留单。输入支持系统运单号、客户单号、FBA 号以及批量粘贴；先解析为稳定的运单 ID，再查询是否被其他预留单占用，编辑时排除当前预留单。重复项保留并标红，字段下逐票显示占用预留单及状态，支持单条移除和「移除全部重复运单」，保留全部其他表单内容。一号多票禁止勾选被占用的候选，移除重复项时保留可用候选。输入阶段即时反馈，保存时必须再次校验；有冲突时整单不保存并定位字段。后端通过事务及关联表唯一约束保证同一运单只有一个占用者，并将并发冲突回传为相同的业务错误。取消后是否释放占用须经产品确认，当前原型按全状态不可重复处理。按本文文案实现，不提供强制覆盖已有关联的入口。

## 权限与正式接入

仅有新增/编辑预留单权限的角色可修改关联；查看权限不因此扩大。正式接口返回的占用单号、客户及状态必须符合调用者可见范围；无查看权限时显示「该运单已被其他预留单占用，请联系有权限的人员处理」，不泄露单据详情。此次是本地前端原型，未接入真实鉴权或后端服务。

前端读取浏览器中全部预留单并监听跨标签页更新，提交前重读最新数据；这不能保证跨用户或同时提交的全局一致性。正式服务必须对租户范围内的实际运单 ID 设置唯一约束，并在事务中写入；若以后允许取消后复用，应将唯一约束限定在有效占用记录上。接口异常时保留输入并阻止提交，提供重试。字段唯一性属于信息关联规则，不改变货物运踪节点。

当前批量预留入口没有运单号导入列；本次批量校验覆盖运单号字段中的多号输入。未来增加导入列时，必须同时检查批内互相重复和已存在占用，列出行号、运单号及占用预留单，不静默部分成功。
