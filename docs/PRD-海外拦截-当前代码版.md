## 2. 项目背景

货物进入海外运输或海外仓作业阶段后，客户可能因订单取消、地址变更、订单资料异常、运输计划调整等原因，要求暂停后续出库或派送。原有流程依赖客服、运营和海外仓在线下沟通，存在申请信息不完整、处理状态不透明、费用记录分散、结果不可追溯等问题。

海外拦截模块用于承接从运单发起拦截申请，到海外仓确认、处理、反馈结果、费用登记、附件维护、日志追踪以及拦截成功后生成海外暂存单的完整流程。

## 3. 产品目标

1. 支持客服或运营从运单列表对单票或多票运单发起海外拦截。
2. 统一管理待处理、处理中、成功、失败和取消的拦截任务。
3. 支持海外仓单条或批量确认、取消及反馈处理结果。
4. 在处理前校验货物状态和未核销指令费用，降低错误操作风险。
5. 拦截成功后自动生成海外暂存单，衔接后续暂存业务。
6. 集中维护货箱、费用、附件、备注和操作日志，实现全流程可追溯。

## 4. 产品范围

### 4.1 本期范围

- 运单列表发起海外拦截申请。
- 单票和批量提交拦截申请。
- 海外拦截任务列表、筛选、状态分组和导出。
- 单条和批量确认拦截、取消拦截、反馈拦截成功或失败。
- 拦截详情、货箱信息、费用信息、附件及备注管理。
- 指令费用核销状态提示。
- 拦截成功后生成并跳转查看海外暂存详情。
- 操作日志记录和查看。

### 4.2 不在本期范围

- 海外仓真实 WMS 拦截指令下发。
- 短信、邮件、企业微信等外部消息通知。
- 财务核销的完整审批和收付款流程。
- 暂存单后续重新下单、转运和出库流程。
- 柜号的列表展示、搜索、详情展示及导出。
- 移动端专用页面。

## 5. 用户角色与权限

| 角色 | 核心诉求 | 主要权限 |
| --- | --- | --- |
| 客服/运营 | 根据客户要求及时发起和跟踪拦截 | 发起申请、查看任务、取消待处理申请、编辑客户备注、查看日志 |
| 海外仓操作员 | 确认货物状态并执行拦截 | 确认拦截、反馈成功/失败、编辑内部备注、维护附件和费用 |
| 财务人员 | 查看费用及核销情况 | 查看费用、查看指令费用与核销状态；费用编辑权限按后台角色配置 |
| 管理员 | 查看全量任务并处理异常 | 全部查看、处理、导出和配置权限 |

> 当前前端原型未实现角色级按钮鉴权；正式上线时应由后端权限点和前端按钮权限共同控制。

## 6. 名词定义

| 名词 | 定义 |
| --- | --- |
| 海外拦截 | 货物进入海外作业链路后，在出库或派送前尝试暂停后续操作的业务动作 |
| 拦截单 | 每次海外拦截申请生成的业务单据 |
| 指令费用 | 运单原有操作指令产生的费用，可随拦截任务带入 |
| 核销状态 | 指令费用或相关费用的财务核销结果，包括待核销、部分核销、已核销 |
| 暂存单 | 拦截成功后，系统为被拦截货物自动生成的海外暂存业务单据 |
| 实际拦截箱数 | 海外仓最终确认成功拦截的箱数，不得超过申请拦截箱数 |

## 7. 整体业务流程

```text
运单列表勾选运单
        ↓
填写拦截原因、上传附件
        ↓
二次确认风险与可能费用
        ↓
生成海外拦截任务
        ↓
海外仓处理
   ┌────┼──────────────┐
   ↓    ↓              ↓
取消申请 确认拦截       已出库校验失败
   ↓    ↓              ↓
已取消  拦截中          拦截失败
          ↓
     ┌────┴────┐
     ↓         ↓
  拦截成功    拦截失败
     ↓
自动生成海外暂存单
     ↓
查看暂存详情
```

## 8. 状态设计

### 8.1 拦截状态

| 状态值 | 页面显示 | 说明 | 可执行操作 |
| --- | --- | --- | --- |
| 待处理 | 待处理 | 拦截申请已创建，等待海外仓确认 | 详情、处理、确认拦截、取消申请、日志 |
| 拦截中 | 处理中 | 海外仓已确认，正在执行拦截 | 详情、处理、拦截成功、拦截失败、日志 |
| 拦截成功 | 拦截成功 | 货物已成功拦截并转入暂存 | 详情、查看暂存详情、日志 |
| 拦截失败 | 拦截失败 | 因已出库、找不到货物等原因无法拦截 | 详情、日志 |
| 已取消 | 取消 | 待处理阶段由客服或运营取消 | 详情、日志 |

### 8.2 状态流转规则

| 当前状态 | 操作 | 目标状态 | 必填/校验 | 系统动作 |
| --- | --- | --- | --- | --- |
| 待处理 | 确认拦截 | 拦截中 | 校验货物是否出库；存在未核销指令费用时二次提示 | 记录处理人、处理时间及日志 |
| 待处理 | 确认拦截 | 拦截失败 | 货物已出库 | 写入失败原因“货物已完成出库”及系统日志 |
| 待处理 | 取消申请 | 已取消 | 取消原因必填，最多 200 字 | 写入结果备注、内部备注及日志 |
| 拦截中 | 拦截成功 | 拦截成功 | 实际拦截箱数为 1 至申请箱数 | 自动生成暂存单号，更新货物为暂存状态，记录日志 |
| 拦截中 | 拦截失败 | 拦截失败 | 失败原因必填，最多 200 字 | 写入失败原因、结果备注及日志 |

### 8.3 状态终态

“拦截成功”“拦截失败”“已取消”为当前版本终态。终态任务不可再次确认、取消或反馈处理结果，仅支持查看详情、查看日志及相关信息维护。

## 9. 功能需求

### 9.1 从运单列表发起海外拦截

#### 9.1.1 入口

- 页面：运单列表。
- 入口按钮：`海外拦截`。
- 支持勾选单票或多票运单后批量发起。
- 未勾选运单时点击，提示“请先在下方列表中勾选需要拦截的运单，支持批量选择”。

#### 9.1.2 申请弹窗

| 字段 | 控件 | 必填 | 规则 |
| --- | --- | --- | --- |
| 运单号 | 标签集合 | 是 | 展示全部已勾选运单号及总票数，只读 |
| 拦截原因 | 多行文本 | 是 | 最多 500 字；为空时不可继续提交 |
| 文件附件 | 文件上传 | 否 | 单文件，最大 100MB；展示已选文件名 |

#### 9.1.3 二次确认

保存申请前展示风险提示：

> 海外仓将尝试进行拦截，但无法保证 100% 拦截成功。拦截过程中可能产生拦截费、操作费等相关费用，具体费用以实际账单为准。

用户可选择“返回修改”或“继续提交”。

#### 9.1.4 提交结果

每个已选运单生成一条独立拦截任务，带入以下信息：

- 拦截单号。
- 运单号、客户单号、客户名称。
- 仓库、申请箱数。
- 拦截原因、客户备注、附件名称。
- 运单原有指令费用。
- 申请时间。

同时在原运单备注中追加“海外拦截：{拦截原因}”；若上传附件，则同步加入原运单附件列表。提交成功后自动打开“海外拦截”页，并定位到“处理中”状态分组。

### 9.2 海外拦截列表

#### 9.2.1 筛选区

| 筛选项 | 控件 | 匹配规则 |
| --- | --- | --- |
| 拦截单号 | 输入框 | 包含匹配，不区分大小写；支持回车搜索 |
| 运单号 | 输入框 | 包含匹配，不区分大小写 |
| 客户单号 | 输入框 | 包含匹配，不区分大小写 |
| 最新运踪 | 输入框 | 关键词包含匹配，不区分大小写 |
| 客户名称 | 下拉框 | 精确匹配，选项来自当前任务客户集合 |
| 核销状态 | 下拉框 | 待核销、部分核销、已核销 |
| 申请时间 | 日期范围 | 起止日期均包含边界 |

操作：

- `搜索`：按当前筛选条件刷新列表。
- `重置`：清空筛选、清空勾选并切换至“全部”。
- 本模块不提供柜号筛选。

#### 9.2.2 状态分组

状态页签及数量统计：待处理、处理中、拦截成功、拦截失败、取消、全部。切换状态页签时清空已选记录。

#### 9.2.3 列表字段

| 序号 | 字段 | 说明 |
| --- | --- | --- |
| 1 | 勾选框 | 支持单选、全选和半选状态 |
| 2 | 客户名称 | 拦截任务所属客户 |
| 3 | 拦截单号 | 拦截业务唯一编号 |
| 4 | 运单号 | 来源运单编号 |
| 5 | 客户单号 | 客户侧订单编号 |
| 6 | 最新运踪 | 当前最新货物轨迹描述 |
| 7 | 拦截原因 | 发起人填写的申请原因 |
| 8 | 拦截箱数 | 优先展示实际拦截箱数，否则展示申请箱数 |
| 9 | 指令费用 | 展示金额、币种、费用名称、单价和单位 |
| 10 | 核销状态 | 待核销、部分核销或已核销 |
| 11 | 客户备注 | 客户相关备注 |
| 12 | 内部备注 | 内部处理备注，空时回退展示普通备注 |
| 13 | 申请人 | 申请创建人 |
| 14 | 申请时间 | 任务创建时间 |
| 15 | 处理人 | 最近处理人 |
| 16 | 处理时间 | 最近处理时间 |
| 17 | 操作 | 详情、处理、日志 |

说明：

- 列表不展示柜号。
- 操作列固定在表格右侧，按钮须完整显示。
- “处理”仅在待处理和拦截中状态展示。
- 分页默认展示 50 条/页；正式版本需由服务端分页。

#### 9.2.4 行内操作

| 操作 | 展示条件 | 结果 |
| --- | --- | --- |
| 详情 | 全部状态 | 以只读模式打开拦截详情抽屉 |
| 处理 | 待处理、拦截中 | 以处理模式打开详情，底部展示当前状态可执行按钮 |
| 日志 | 全部状态 | 打开操作日志弹窗 |

### 9.3 批量操作

#### 9.3.1 待处理页签

| 操作 | 规则 |
| --- | --- |
| 批量取消拦截 | 至少勾选一条待处理任务；取消原因必填，最多 200 字 |
| 批量确认拦截 | 至少勾选一条待处理任务；已出库任务自动转为拦截失败；存在未核销或部分核销指令费用时二次确认 |

#### 9.3.2 处理中页签

| 操作 | 规则 |
| --- | --- |
| 批量拦截成功 | 至少勾选一条拦截中任务；备注选填，最多 200 字；为每条任务生成独立暂存单 |
| 批量拦截失败 | 至少勾选一条拦截中任务；失败原因必填、备注选填，均最多 200 字 |

#### 9.3.3 通用操作

- 未选择记录时提示“请勾选运单”。
- 操作完成后清空已选记录。
- 批量处理仅作用于当前状态页签内已勾选且符合状态条件的记录。

### 9.4 导出

- 至少勾选一条当前筛选结果中的记录才可导出。
- 文件格式：CSV，UTF-8 BOM。
- 文件名：`拦截管理_{当前状态}_{YYYY-MM-DD}.csv`。
- 导出字段与列表业务字段一致，但不包含勾选框、操作列和柜号。
- 导出记录范围为当前页面已勾选记录。

### 9.5 拦截详情

#### 9.5.1 详情头部

- 展示拦截单号、当前状态和运单号。
- 展示流程节点：提交申请 → 确认拦截 → 仓库处理中 → 完成/拦截失败/已取消。
- 支持右上角关闭、点击遮罩关闭和按 `Esc` 关闭。

#### 9.5.2 基础信息

| 字段 | 展示/操作规则 |
| --- | --- |
| 客户名称 | 只读 |
| 拦截单号 | 只读、高亮 |
| 入仓号 | 当前由来源运单号映射展示 |
| 拦截原因 | 只读 |
| 拦截箱数 | 优先实际箱数，否则申请箱数 |
| 核销状态 | 状态标签展示 |
| 申请人 | 只读 |
| 申请时间 | 只读 |
| 客户备注 | 可编辑，最多 200 字；保存后记录日志 |
| 内部备注 | 除已取消状态外可编辑，最多 200 字；保存后记录日志 |

基础信息不展示柜号。

#### 9.5.3 详情页签

详情包含“货箱信息”“费用信息”“其它信息”三个页签。

### 9.6 货箱信息

| 字段 | 说明 |
| --- | --- |
| 货箱号 | 按任务标识和箱序号生成的货箱编号 |
| 客户数据 | 客户名称、拦截单号 |
| 系统拣货（材重/实重） | 系统拣货序号、材重和实重信息 |

货箱状态随拦截状态映射：

- 待处理 → 待确认。
- 拦截中 → 拦截处理中。
- 拦截成功 → 已转暂存。
- 拦截失败 → 拦截失败。
- 已取消 → 已取消。

当前原型最多渲染 12 条货箱明细；正式版本应展示实际全部货箱并支持分页或虚拟滚动。

### 9.7 费用信息

#### 9.7.1 费用列表

| 字段 | 说明 |
| --- | --- |
| 计费时间 | 费用发生或计费时间 |
| 费用名称 | 如拦截操作费、仓储费、卸柜费 |
| 费用类型 | 操作费、仓储费或其他 |
| 计费单位 | 票、箱、KG 等 |
| 汇率 | 人民币默认为 1；外币可维护汇率 |
| 单价 | 原币单价 |
| 数量 | 计费数量 |
| 币种 | 人民币或其他币种 |
| 原币应收金额 | 单价 × 数量 |
| 人民币应收金额 | 原币应收金额 × 汇率 |
| 费用备注 | 费用说明 |
| 添加时间 | 费用记录创建时间 |
| 添加人 | 费用记录创建人 |
| 操作 | 编辑、删除 |

#### 9.7.2 费用操作

- 支持新增一条或多条费用。
- 支持编辑费用字段。
- 支持删除费用，删除前二次确认。
- 页面汇总费用条数、原币合计和人民币合计。
- 数字输入需按数值解析；数量为空或为 0 时按 1 处理。
- 正式版本应由后端校验币种、汇率精度、单价和数量范围。

#### 9.7.3 核销状态规则

- 若任务已明确返回核销状态，则以返回状态为准。
- 无明确状态时：无费用为已核销；一条费用为待核销；多条费用为部分核销。
- 存在指令费用且核销状态不是已核销时，确认拦截前必须进行风险提示，但允许用户确认后继续。

### 9.8 其它信息与附件

#### 9.8.1 附件字段

| 字段 | 说明 |
| --- | --- |
| 附件名称 | 文件原始名称 |
| 附件类型 | POD、ISA、报关资料、底单、其他/其它、税金单、递延资料、提单 |
| 客户可见 | 可见或不可见 |
| 文件大小 | 上传文件大小 |
| 上传人 | 操作用户 |
| 上传时间 | 上传时间 |
| 操作 | 编辑、下载、删除 |

#### 9.8.2 附件规则

- 上传附件时文件为必填。
- 详情页上传弹窗提示文件不超过 250MB，正式版本应在前后端同时执行大小校验。
- 若为报关资料，文件类型应选择“报关资料”。
- 支持维护客户是否可见。
- 删除附件前展示确认弹窗。
- 无附件时展示空状态。

### 9.9 单条处理

#### 9.9.1 确认拦截

仅待处理任务可执行：

1. 若货物已出库，系统直接将任务置为拦截失败，并记录系统校验日志。
2. 若存在未核销或部分核销的指令费用，提示用户确认是否仍要拦截。
3. 若货物未拆柜，提示将创建预报拦截任务。
4. 若货物已入库，提示将创建仓库拦截任务。
5. 用户确认后任务进入拦截中。

#### 9.9.2 取消申请

- 仅待处理任务可取消。
- 取消原因必填，最多 200 字。
- 取消后进入已取消状态，并将原因写入结果备注和操作日志。

#### 9.9.3 反馈拦截成功

- 仅拦截中任务可执行。
- 实际拦截箱数必填，须为正整数，范围为 1 至申请箱数。
- 备注选填，最多 200 字。
- 提交后任务进入拦截成功状态。
- 系统生成暂存单号，格式为 `STG + YYYYMMDD + 四位任务序号`。
- 货物状态更新为暂存中，库存状态更新为暂存，出库状态为未出库。

#### 9.9.4 反馈拦截失败

- 仅拦截中任务可执行。
- 失败原因必填，最多 200 字。
- 备注选填，最多 200 字。
- 提交后任务进入拦截失败状态，并保留失败原因和处理记录。

#### 9.9.5 查看暂存详情

拦截成功后，“处理”模式底部展示“查看暂存详情”，点击后打开对应暂存单详情。

### 9.10 操作日志

日志字段：

| 字段 | 说明 |
| --- | --- |
| 操作内容 | 创建任务、确认拦截、取消申请、状态校验、拦截成功、拦截失败、修改备注等 |
| 操作前 | 操作前状态或值 |
| 操作后 | 操作后状态或值 |
| 操作人 | 系统或业务用户 |
| 操作时间 | 操作发生时间 |

以下操作必须生成日志：

- 创建拦截任务。
- 确认拦截。
- 货物已出库校验失败。
- 取消申请。
- 反馈拦截成功或失败。
- 修改客户备注或内部备注。

正式版本的日志应只增不改、不可删除，并由服务端记录真实用户和服务端时间。

## 10. 页面交互规则

1. 列表支持横向和纵向滚动，表头保持吸顶。
2. 操作列固定在右侧，保证“详情 / 处理 / 日志”完整展示。
3. 长文本在列表中单行省略，鼠标悬停展示完整内容。
4. 全选仅作用于当前筛选结果；部分选中时展示半选状态。
5. 切换状态页签或执行重置时清空勾选。
6. 弹窗和抽屉支持遮罩关闭；业务输入弹窗关闭前不自动保存。
7. 多层弹窗按 `Esc` 时优先关闭最上层弹窗。
8. 成功、提示和警告信息以 Toast、确认框或表单校验提示反馈。

## 14. 非功能需求

### 14.1 性能

- 列表查询在 10 万条历史任务规模下，常用筛选响应时间应小于 2 秒。
- 默认分页 50 条，单页最大不超过 200 条。
- 导出超过 5,000 条时应转为异步任务并提供下载中心。

### 14.2 安全

- 附件上传需校验扩展名、MIME 类型、大小和恶意文件。
- 客户不可见附件不得通过客户侧接口访问。
- 费用和处理操作需校验角色权限。
- 日志需记录操作人、时间、来源 IP 或终端信息，并禁止业务用户删除。

### 14.3 一致性

- 拦截任务、运单状态、费用记录和暂存单之间应通过唯一业务 ID 关联。
- 状态更新采用事务与乐观锁，避免多人同时处理造成覆盖。
- 暂存单创建失败时，拦截任务不得落为拦截成功。

### 14.4 可用性

- 所有关键操作均需有明确成功或失败反馈。
- 必填字段在提交前进行前端校验，后端必须重复校验。
- 长文本支持悬停查看完整内容。
- 表格操作列在常用桌面分辨率下应始终可见且按钮不截断。

## 15. 埋点与统计建议

| 指标 | 口径 |

| 拦截申请量 | 按日统计新建拦截任务数 |

## 17. 当前原型与正式上线差异

当前页面为前端原型，以下能力在正式上线前需要服务端化：

1. 任务当前使用前端内存保存，刷新页面后不保证持久化。
2. 分页控件目前为展示效果，需接入真实服务端分页。
3. 拦截单号和暂存单号目前由前端生成，正式版本应由服务端统一生成并保证唯一。
4. 当前操作人使用模拟名称，正式版本应读取登录用户。
5. 货物出库状态、运踪和货箱信息需接入运单系统与 WMS 实时数据。
6. 附件当前主要使用浏览器对象或模拟下载，需接入对象存储和权限下载接口。
7. 费用及核销状态需接入财务系统，核销状态不得仅按费用条数推断。
8. 批量处理需返回逐条执行结果和失败原因。
9. 所有状态变更需增加并发控制、幂等校验和审计日志。

## 18. 待产品确认项

1. 运单页新建任务是否应直接进入“拦截中”，还是统一进入“待处理”。当前代码直接进入“拦截中”。
2. 详情基础信息中的“入仓号”当前使用运单号映射，正式字段来源需确认。
3. 批量拦截成功是否允许每条任务填写不同的实际拦截箱数；当前按各任务已有箱数处理。
4. 详情附件大小上限为 250MB，而运单发起页为 100MB，是否需要统一。
5. 已取消任务是否允许继续编辑客户备注、费用和附件。
6. 拦截失败后是否支持重新发起，还是必须回到运单页新建一张拦截单。
7. 指令费用未核销时是否仅提示，还是应根据客户信用、费用类型或角色阻断。
8. 拦截成功生成暂存单后，是否需要同步更新来源运单主状态。
