## 2. 背景

跨境物流的头程货物到达海外仓后，常出现一票多箱、多批次出库、部分暂存、部分中转、客户临时扣货或销毁等业务场景。若海外暂存库存、箱号占用、下单信息、尾程转单和中转状态分散管理，会产生重复下单、箱号重复占用、地址缺失、费用遗漏、取消/驳回后库存不回流等问题。

当前项目已具备两个核心工作台：

- 海外暂存：以头程母单和可下单箱号为中心，负责暂存货物查询、箱号选择、下单类型选择、收件地址/指令/附件录入，并生成海外中转子单。
- 海外中转单：以子单履约状态为中心，负责待确认、已确认、已下单、转运中、签收、驳回、取消等状态流转，并承载费用、附件、轨迹、转单号和日志。

本 PRD 以当前代码实现为基线，定义产品目标、业务流程、字段规则、状态机、交互和验收标准。

## 3. 产品目标

1. 建立“头程母单 - 箱号 - 海外中转子单 - 转单号”的可追溯链路。
2. 支持海外仓暂存货物按箱拆分、部分下单、批次生成中转子单。
3. 防止箱号重复占用，子单取消或驳回后箱号可回流母单。
4. 支持三类下单类型：放货、不放货、销毁。
5. 将地址、预约发货时间、派送方式、仓储/操作指令、附件随子单传递到海外中转单管理。
6. 通过状态机控制各节点可操作动作，降低误操作。
7. 为业务、跟单、仓库、财务提供统一查询、导出、日志和明细视图。

## 6. 核心概念

| 概念 | 定义 | 当前代码字段 |
| --- | --- | --- |
| 头程母单 | 发往海外仓的一票头程货物，是箱号和暂存库存来源 | `headWaybillNo` / `id` |
| 海外暂存单 | 母单到海外仓后的暂存库存记录 | `OverseasTransitRow` in `OverseasTransitPage` |
| 箱号 | 可独立下单的最小货物单位 | `boxNumbers` |
| 海外中转子单 | 从暂存母单选择若干箱后生成的履约单 | `CreatedTransitChildOrder` |
| 海外仓运单号 | 子单展示编号，由母单号、日期、序号组成 | `getOverseasWaybillNo` |
| 下单类型 | 对货物的处置指令：放货、不放货、销毁 | `releaseInstruction` |
| 运单类型 | 收件地址/平台类型，如 FBA、Walmart、TikTok、私人地址 | `orderType` |
| 派送方式 | 尾程派送方式，如快递派送、卡车派送、客户自提 | `deliveryMethod` |
| 操作指令 | 仓储、拦截、扣货等费用/作业要求 | `instructions` |
| 核销状态 | 财务费用核销状态 | `reconciliationStatus` |
| 是否到达海外仓 | 货物是否到达海外仓确认项 | `overseasWarehouseArrivalStatus` |

## 7. 信息架构

### 7.1 菜单入口

系统侧边栏「海外中转单管理」下包含：

- 海外暂存
- 海外中转单
- 海外仓拦截
- 指令管理

本 PRD 覆盖「海外暂存」和「海外中转单」。

### 7.2 页面关系

海外暂存页面负责生成中转子单，生成后通过 `submitStorageBoxesAsTransitChild` 写入中转单共享数据流；海外中转单页面通过 `getCreatedTransitChildOrders` 和订阅机制读取新增子单，并继续处理状态流转。

```text
海外暂存母单
  -> 勾选箱号
  -> 选择下单类型
  -> 填写地址/指令/附件
  -> 提交
  -> 创建海外中转子单：待确认
  -> 海外中转单管理继续履约
```

## 8. 海外暂存需求

### 8.1 页面目标

帮助业务和仓库人员在海外仓暂存池中查询母单、查看可用库存、选择箱号并提交为海外中转子单。

### 8.2 状态页签

| 页签 | 定义 | 可操作 |
| --- | --- | --- |
| 运输中 | 母单仍在运输或暂未完成海外仓入仓 | 查看、下单、导出、日志 |
| 暂存 | 已进入海外仓暂存，可按箱下单 | 查看、下单、导出、日志 |
| 暂存已完成 | 可下单箱数为 0 或暂存处理完毕 | 只读查看、导出、日志 |

当前 `mode="storage"` 时默认进入「运输中」，并仅展示以上 3 个页签。

### 8.3 搜索区

搜索区支持基础暂存字段和三类标识字段查询。当前代码中真正生效的精确/模糊过滤为：

| 字段 | 控件 | 规则 |
| --- | --- | --- |
| 入仓号 | 输入框 | 模糊匹配 `inboundNo` |
| Shipment ID | 输入框 | 模糊匹配 `shipmentId` |
| Reference ID | 输入框 | 模糊匹配 `referenceId` |

其他展示型搜索项用于后续扩展，包括头程运单号、FBA 单号、客户单号、客户简称、中转单类型、件数、服务、代理、备注、入仓时间、仓租时间等。

### 8.4 列表字段

运输中状态隐藏部分入仓和仓租字段；暂存和暂存已完成展示更完整字段。

核心列表字段包括：

- 头程运单号
- 入仓号
- Shipment ID
- Reference ID
- 客户单号
- 运单箱数
- 可下单箱数
- 备注
- 入仓时间（海外仓）
- 仓龄
- 转单号
- 仓库代码
- 收费重
- 实重
- 材积重
- 方数
- 邮编

### 8.5 详情抽屉

点击查看/下单进入详情抽屉。详情抽屉包含：

- 母单基础信息
- 箱号列表和可用状态
- 下单类型
- 收件地址信息
- 附件上传
- 操作指令/费用
- 提交/取消按钮

### 8.6 箱号选择规则

1. 用户必须至少选择 1 个有效箱号才能提交。
2. 已被提交到子单的箱号从母单可用箱数中扣减。
3. 已移除箱号通过 `getRemovedStorageBoxNumbers` 标识，避免重复选择。
4. 暂存已完成状态不可再选择箱号。

### 8.7 下单类型规则

| 下单类型 | 含义 | 地址是否必填 | 生成子单后语义 |
| --- | --- | --- | --- |
| 放货 | 正常出库/尾程派送 | 是 | 按收件地址继续履约 |
| 不放货 | 暂不安排尾程派送 | 否 | 记录扣货/暂不放货指令 |
| 销毁 | 货物不再派送，进入销毁处置 | 否 | 记录销毁处置指令 |

默认值为「放货」。选择「不放货」或「销毁」时，逻辑等同旧版“是否出货=否”，不展示/不校验收件地址必填项。

### 8.8 放货地址规则

下单类型为「放货」时，提交前必须校验：

- 预约发货时间必填
- 派送方式必填
- 运单类型必填
- 仓库代码必填
- 邮编必填
- 城市必填
- 地址详情必填

仓库代码输入后，如匹配地址簿，自动带出邮编、收件人、城市、州、地址详情。

运单类型选项：

- FBA
- Walmart
- TikTok
- 私人地址

运单类型为私人地址时，电话为必填项。

### 8.9 附件规则

1. 支持上传 1 个附件并显示文件名和大小。
2. 支持删除已选择附件。
3. 提交后附件随中转子单传递到海外中转单详情。
4. 附件默认客户可见，上传人为当前操作员。

### 8.10 操作指令/费用规则

操作指令支持选择、编辑和删除。当前费用池包括：

- 仓储渠道-免仓30天
- 仓储渠道-31-90天
- 仓储渠道-90天以上
- 拦截-免仓7天
- 拦截-免仓8-90天
- 拦截-免仓90天以上
- 扣货-无免仓期

费用字段包括费用代码、费用名称、费用类型、计费单位、计费单价、计费数量、币种、费用金额、添加时间、添加人、描述。金额按 `单价 * 数量` 计算。

### 8.11 提交结果

提交成功后：

1. 生成 `CreatedTransitChildOrder`。
2. 子单状态为「待确认」。
3. 记录父级头程母单号。
4. 记录本次提交箱号。
5. 扣减母单可用箱数。
6. 清空当前母单已选箱号、附件、操作指令草稿。
7. 海外中转单管理页面可立即看到新增子单。

## 9. 海外中转单需求

### 9.1 页面目标

承接海外暂存生成的中转子单，提供确认、下单、出运、签收、驳回、取消、费用、附件、轨迹、转单号维护等履约能力。

### 9.2 状态页签

| 状态 | 定义 |
| --- | --- |
| 待确认 | 已创建子单，等待业务/跟单确认 |
| 已确认 | 子单信息已确认，可创建快递单或确认下单 |
| 已下单 | 已完成中转下单，等待出运 |
| 转运中 | 已出仓/转运中 |
| 签收 | 尾程已签收 |
| 驳回 | 待确认子单被驳回，需补充后重新下单或作废 |
| 取消 | 子单取消或驳回后作废 |

### 9.3 搜索区

所有状态支持通用搜索；部分状态支持额外生命周期日期和到仓字段。

| 字段 | 控件 | 规则 |
| --- | --- | --- |
| 头程运单号 | 输入框 | 展示型，后续扩展批量查询 |
| 海外仓运单号 | 输入框 | 展示型，后续扩展批量查询 |
| 柜号 | 输入框 | 展示型，后续扩展批量查询 |
| 提单号 | 输入框 | 展示型，后续扩展批量查询 |
| 入仓号 | 输入框 | 模糊匹配 `inboundNo` |
| Shipment ID | 输入框 | 模糊匹配 `shipmentId` |
| Reference ID | 输入框 | 模糊匹配 `referenceId` |
| 核销状态 | 下拉 | 匹配已核销、未核销、部分核销 |
| 客户简称 | 下拉 | 展示型，后续扩展 |
| 仓库代码 | 下拉 | 展示型，后续扩展 |
| 下单类型 | 下拉 | 匹配放货、不放货、销毁 |
| 运单类型 | 下拉 | 展示型，FBA/Walmart/TikTok/私人地址 |
| 派送方式 | 下拉 | 匹配快递派送、卡车派送、客户自提 |
| 是否到达海外仓 | 下拉 | 待确认、已确认、已下单、驳回状态展示 |
| 下单时间 | 日期 | 已下单状态展示 |
| 出仓时间 | 日期 | 转运中状态展示 |
| 签收时间 | 日期 | 签收状态展示 |

- 子单创建时间

- 转单号

- Shipment ID

- 柜号
- 提单号
- 客户简称
- 仓库代码
- 邮编

- 派送方式

- 海外仓备注
- 业务员

- 重量

### 9.5 状态操作

| 当前状态 | 操作 | 目标状态 | 规则 |
| --- | --- | --- | --- |
| 待确认 | 取消下单 | 取消 | 子单箱号回流母单 |
| 待确认 | 驳回 | 驳回 | 必填驳回原因，子单数据回流母单 |
| 待确认 | 已确认 | 已确认 | 放货单必须有预约发货时间和派送方式 |
| 已确认 | 取消下单 | 取消 | 子单箱号回流母单 |
| 已确认 | 创建快递单 | 状态不变 | 进入快递打单工作区 |
| 已确认 | 确认下单 | 已下单 | 若存在未核销费用或未到海外仓需二次确认 |
| 已下单 | 回退 | 已确认 | 清空下单/出仓/签收时间 |
| 已下单 | 出运 | 转运中 | 写入出仓时间 |
| 转运中 | 签收 | 签收 | 写入签收时间 |
| 转运中 | 回退 | 已下单 | 清空出仓/签收时间 |
| 签收 | 回退 | 转运中 | 清空签收时间 |
| 驳回 | 重新下单 | 待确认 | 需重新完善下单信息并选择操作指令 |
| 驳回 | 作废 | 取消 | 子单进入取消列表 |

### 9.6 待确认详情/编辑

待确认或驳回重新下单时，详情页展示可编辑下单表单：

- 下单类型：放货、不放货、销毁
- 放货时展示收件地址信息
- 不放货/销毁时隐藏地址必填校验
- 运单类型、仓库代码、邮编、收件人、电话、城市、州、公司、地址详情
- 预约发货时间
- 派送方式
- 客户备注
- 海外仓备注
- 附件上传
- 操作指令

编辑时支持保存和取消；取消恢复编辑前快照。

### 9.7 已确认及后续详情

已确认、已下单、转运中、签收等状态展示子单基础信息及多个详情页签：

- 费用信息
- 货物信息
- 运踪
- 其他信息/附件
- 操作日志

基础信息展示下单类型、运单类型、仓库代码、入仓号、Shipment ID、Reference ID、核销状态、是否到达海外仓、柜号、提单号、发货件数、重量、方数、转单号、头程运单号、子单创建时间、邮编、业务员、跟单员、备注等。

### 9.8 快递单创建工作区

在「已确认」状态，用户可选择子单进入快递单创建工作区：

- 按线路区分美线打单、欧线打单。
- 展示校验状态、海外仓运单号、头程运单号、客户简称、目的地/仓库、收件人/地址、邮编、箱数/实重、运单类型、尾程渠道、打单平台、发货账号/服务、快递单号/创建时间、操作。
- 资料异常或已创建记录不可重复创建。
- 创建后记录快递单号、创建时间、平台、账号、服务。

### 9.9 转单号维护

转运相关详情中支持维护按箱转单明细：

- 系统箱号
- FBA 箱号
- 承运公司
- 转单号

保存后用于后续查询、跟踪和对账。

### 9.10 运踪管理

支持新增运踪事件：

- 运踪时间
- 运踪节点
- 地点
- 运踪描述

运踪按时间线展示，最新节点高亮。

### 9.11 附件管理

支持附件上传、编辑、删除、下载展示：

- 文件名
- 类型
- 客户是否可见
- 上传时间
- 上传人
- 文件大小

地址页上传的附件可并入子单附件列表。

### 9.12 操作日志

日志记录关键状态变更和费用操作：

- 变更时间
- 操作人
- 操作类型
- 变更字段

## 11. 关键业务规则

1. 暂存提交必须选择至少 1 个有效箱号。
2. 同一个箱号同一时间只能被一个有效中转子单占用。
3. 待确认取消或驳回时，子单箱号需要回流母单。
4. 驳回重新下单时，必须重新选择操作指令。
5. 放货单进入确认前必须校验预约发货时间和派送方式。
6. 放货单保存地址时必须校验完整收件地址。
7. 不放货和销毁不校验收件地址。
8. 已确认确认下单时，如存在未核销/部分核销费用，需二次确认。
9. 已确认确认下单时，如货物未到海外仓，需二次确认。
10. 已下单出运写入出仓时间；转运中签收写入签收时间。
11. 回退状态时需清空相应生命周期时间。
12. 所有批量操作必须先勾选当前状态下的记录。
13. 取消、驳回、作废等高风险操作必须有确认弹窗或原因录入。

## 15. 验收标准

### 15.1 海外暂存

- 进入「海外暂存」默认展示运输中页签。
- 可按入仓号、Shipment ID、Reference ID 搜索并重置。
- 可打开暂存详情并勾选有效箱号。
- 下单类型默认放货。
- 选择放货时，提交必须校验地址、预约发货时间和派送方式。
- 选择不放货或销毁时，不展示/不校验地址信息。
- 成功提交后生成待确认海外中转子单。
- 成功提交后母单可用箱数扣减，已提交箱号不可重复选择。
- 附件和操作指令可随子单带入。

### 15.2 海外中转单

- 新生成子单出现在「海外中转单」待确认页签。
- 所有状态列表展示下单类型列。
- 可按下单类型搜索放货、不放货、销毁。
- 待确认可取消、驳回、确认。
- 已确认可取消、创建快递单、确认下单。
- 已下单可回退或出运。
- 转运中可签收或回退。
- 签收可回退。
- 驳回可重新下单或作废。
- 取消、驳回后箱号回流母单。
- 生命周期时间随状态变化正确写入或清空。
- 详情页展示下单类型和运单类型。

## 16. 研发实现建议

## 18. 待确认问题

1. 不放货和销毁是否需要单独状态，还是仅作为下单类型字段保留在待确认/已确认流程中。
2. 销毁是否需要强制上传客户授权附件。
3. 不放货是否应进入仓储计费周期，并自动生成仓储费用。
4. 放货后是否必须创建快递单，还是允许手工确认下单。
5. 海外仓到达状态由人工维护还是由 WMS/轨迹接口回传。
6. 核销状态由财务系统推送还是本模块人工编辑。
7. 私人地址电话、州、公司等字段在不同国家是否需要差异化校验。
8. 附件客户可见性是否需要同步到客户门户。
