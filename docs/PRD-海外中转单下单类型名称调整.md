# PRD：海外中转单下单类型名称调整

## 一、修改内容

| 原名称 | 新名称 |
| --- | --- |
| 放货 | 发货 |
| 不放货 | 增值服务 |
| 销毁 | 销毁，保持不变 |

## 二、需要同步修改的位置

1. 海外暂存页面生成海外中转单时，“下单类型”的单选项名称。
2. 海外中转单查询区中，“下单类型”的下拉选项名称。
3. 海外中转单列表中，“下单类型”列的展示名称。
4. 海外中转单的下单和重新下单表单中，“下单类型”的单选项名称。
5. 海外中转单详情中，“下单类型”字段的展示名称。
6. 海外中转单各状态页签中出现上述名称的位置。

## 三、说明

本次仅修改页面展示名称，不修改原有业务逻辑、数据值和校验规则。
